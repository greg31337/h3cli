# Source layout

The top level contains `h3cli.c`, `engine.c`, `h3.h`, internal/shared interfaces,
host geometry, backend selection, platform helpers, memory, profiling and hashing.

| Directory | Responsibility |
|---|---|
| `cli/` | Progress reporting and terminal display |
| `conditioning/` | Text/vision encoders, tokenization, multimodal presentation and conditioning caches |
| `denoise/` | DiT, schedules, attention policy, adaptive cache and SubBlock |
| `sampling/` | Sampler checkpoints, AV state, continuation and bridge policy |
| `vae/` | Image, video, audio and tiny VAE models and encoding/decoding |
| `media/` | FFmpeg I/O, resizing, reference video preparation, previews and final delivery |
| `weights/` | Safetensors, weight loading/residency, LoRA folding and quantization |
| `upscale/` | Latent upscaling state, network, refinement and GPU kernels |
| `metal/` | Metal/MPSGraph and ANE implementation, shaders and tiny VAE backend |
| `cuda/` | CUDA implementation, kernels, attention libraries and tiny VAE backend |
| `sglang/` | Shared SGLang arithmetic, media preprocessing and RNG compatibility |
| `testing/` | Bounded diagnostic teacher loading used by validation tools |

Includes use repository-relative paths, with the repository root on the include
search path. The Makefile lists compilation units explicitly and discovers source
identity inputs and dependency files recursively. Executables and `libh3.a` go
under the gitignored `bin/` directory; `make clean` removes nested object and
dependency files as well.

`metal/native_attention.inc` is generated by `scripts/embed_metal_attention.py`
and is gitignored. `metal/shaders.metal` is a runtime resource: preserve its path
relative to the repository/install root, or supply `H3_SHADER_PATH` explicitly.
