# Historical campaign records

These four manifests describe completed multi-reference performance/quality
campaigns and their original assets. They are not numerical golden outputs or
prerequisites of the retained functional suite. Archived report tools still
read them; reproducing a campaign requires its original external evidence.
Only `tests/cuda_reference/manifest.json` defines the recorded numerical gate.

Private model paths have been normalized and the historical GPU UUID removed.
The recorded campaign identity describes the original private manifest, not the
sanitized copy. Numerical/media hashes are unchanged. New runs write their
machine-specific manifests only to ignored `outputs/`, never to this archive.
